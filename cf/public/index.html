Parsec보다 빠르게, 어디서든 내 PC로. 서브프레임 전송 파이프라인과 FEC 손실 복구, 제로레이턴시 커서로 원격인 걸 잊게 만드는 것이 목표.

네이티브 클라이언트 다운로드 웹에서 바로 접속
Windows x64 H.264 / HEVC 1080p 60fps WebRTC + TCP 폴백

왜 BetterParsec인가

기성품이 대충 넘어가는 지점을 전부 직접 계측하고 고쳤다.

Latency

서브프레임 파이프라인

호스트 처리 지연 3ms 이하. 프레임이 완성되기 전에 슬라이스 단위로 전송을 시작하는 파이프라인을 향해 설계됨.

Reliability

FEC 손실 복구

패킷이 사라져도 재전송을 기다리지 않는다. RaptorQ 계열 FEC로 손실 스팬을 그 자리에서 복원.

Input

제로레이턴시 커서

커서를 클라이언트에서 직접 그린다. 마우스가 네트워크를 기다리지 않는 로컬 반응성. FPS용 포인터락 자동 전환 포함.

Session

스톨 워치독

화면이 멈추면 IDR 재요청, ICE 재시작, 세션 재접속까지 자동 사다리로 복구. 새로고침할 일이 없어야 정상.

Immersive

몰입 모드

전체화면 + 키보드락 + 포인터락 원터치. Alt+Tab, Win키까지 원격 PC로 전달되는 게이밍 모드.

Workflow

클립보드 동기화

양방향 텍스트 클립보드. 복사는 저쪽에서, 붙여넣기는 이쪽에서.

다운로드

네이티브 클라이언트는 웹보다 한 단계 낮은 지연과 하드웨어 디코딩 제어를 제공한다.

BetterParsec Portable (Windows x64)

  • 압축 해제 후 설치 없이 바로 실행
  • FFmpeg 하드웨어 디코더 포함 (약 62 MB)
  • 동봉된 run-incheon.bat 실행이면 끝

비밀번호가 올바르지 않습니다.

사용법

처음 받는 사람 기준 3단계.

  1. zip을 받아 원하는 폴더에 압축 해제한다.
  2. run-incheon.bat을 실행한다. 자체 서명 인증서 경고가 뜨면 계속을 누른다.
  3. 계정으로 로그인하면 호스트 PC 화면이 뜬다. 웹 접속은 상단의 "웹에서 바로 접속" 버튼.
BetterParsec — 개인 프로젝트. 배포 빌드는 호스트에서 서명 없이 패키징된다.
